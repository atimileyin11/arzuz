📈 Marketing

Lands on Growth — traction, funnel, channels, what to do next — plus the Strategy docs (positioning, channels, growth model first). No student phone numbers, no tables, no settings.

To add a marketing teammate (≈2 minutes):

  1. Supabase dashboard → Authentication → Users → Add user → her email + a temporary password.
  2. Open that user in the list → find the Raw User JSON (or app_metadata editor) and make it read: 
    "app_metadata": { "role": "marketing" }
    Leave user_metadata untouched.
  3. Send her arzuz.com/admin.html with the email + password; she changes nothing else — her sidebar shows only Growth and Strategy.

The role rides inside her Supabase session token; the dashboard reads it via ArzuzAuth.role(). To make someone a main admin again, remove the role key from app_metadata (or set "role": "admin").

Telegram Instant Alerts

Every student, landlord and scout submission sends an alert to your Telegram. The bot token is held by Netlify as TELEGRAM_BOT_TOKEN and is never sent to the browser.

Once you have a chat ID, paste it into Netlify → Site configuration → Environment variables → TELEGRAM_CHAT_ID and redeploy. Nothing about the bot is stored in this page.
