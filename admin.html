Manual fallback (Supabase dashboard)

If the panel above is unavailable (SUPABASE_SERVICE_ROLE_KEY not set in Netlify), create users by hand: Supabase → Authentication → Users → Add user, then edit the Raw User JSON so app_metadata reads { "role": "support" } or { "role": "marketing" }. No role key = main admin. The dashboard reads it via ArzuzAuth.role().

Test data

Rows submitted with ENV = test are hidden from every table and metric. Show them only when debugging.

Telegram Instant Alerts

Every student, landlord and scout submission sends an alert to your Telegram. The bot token is held by Netlify as TELEGRAM_BOT_TOKEN and is never sent to the browser.

Once you have a chat ID, paste it into Netlify → Site configuration → Environment variables → TELEGRAM_CHAT_ID and redeploy. Nothing about the bot is stored in this page.
